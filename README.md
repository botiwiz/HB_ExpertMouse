# HB Miscellaneous small apps and extensions

Blender add-ons. Each folder has its own README and a ready-to-install `.zip`:

- [HB_BetterBevel](blender_betterbevel/README.md): non-destructive tube-boolean bevel with an adjustable profile (Geometry Nodes), plus Grid Fill clean-up.
- [HB_BevelFix](blender_bevelfix/README.md): fixes bevels that overlap or fold, plus Boolean Bevel and loop-select tools.
- [HB_Caliper](blender_caliper/README.md): measurements that stay visible in every mode.
- [ASCII FBX Importer](blender_fbx_ascii/README.md): imports ASCII FBX files, which Blender's built-in importer rejects.
- [HB_Workplane](blender_workplane/README.md): a temporary construction plane, like Plasticity's.
- [HB_RetopoPen](blender_retopopen/README.md): draw patch outlines on the surface and get quad patches; includes a relax / tweak brush.
